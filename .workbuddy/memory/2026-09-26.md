### 本轮修掉的 4 个真问题

1. **`tdxzs.cfg` 第 6 列不是名字**：145 个行业板块那列放的是 **T 码**（`T0101`/`T030203`），
   32 个地区板块放**序号**（`1`/`2`）。原来只挡纯数字 → 界面会出现叫「T030203」的板块。
   → 加 `_CODE_LIKE = ^(?:[Tt]\d+|\d+)$` 一并回退，`PARSE_VERSION` 2→3。
   注意：概念/风格那 53 个「显示名 ≠ 短名」是**真正的全称，必须保留**。
2. **一级行业板块本来就不存在**（认知纠正）：T 码 145 条里 13 个一级（`T01`…`T13`）
   在 `tdxzs.cfg` 里叫「TDX 交运」这类别名，与 `incon.dat` 名称对不上 →
   匹配集 132 = 二级 56 + 三级 76，**没有一个一级**。所以前缀聚合真正救的是**二级**板块
   （每只股票的归属码实测都是三级码）。例：煤炭开采(T010101) 25 只 ⊂ 煤炭(T0101) 32 只。
3. **板块指数 K 线缺 `pct` 列**：`_index_bars` 只从 `.day` 拼了 OHLCV，没算涨跌幅，
   而个股走缓存带 `pct` → 指数图 tooltip 少一个字段。已在 `_index_bars` 里补
   `df["pct"] = df["close"].pct_change()`（与前收口径一致；窗口首根 NaN，但调用方多读 70 根）。
4. 既有问题回顾（本轮之前）：`_index_bars` 缓存键须带**已读根数**、排序缺值沉底、
   `summary` 在 limit 前统计。

## 本轮附带修的既有问题

- `stock_picker/README.md` 里「一二级行业板块会一个成员都没有」的说法**不准确**：

可行替代：**Node 22 自带全局 `WebSocket`**，所以能写**零依赖**的 CDP 驱动脚本：

```
chrome.exe --headless=new --remote-debugging-port=9333 --user-data-dir=<temp>
        --window-size=1680,1180 about:blank
```

然后 `GET http://127.0.0.1:9333/json/list` 取 `webSocketDebuggerUrl`，用
`Page.enable` / `Runtime.enable` / `Emulation.setDeviceMetricsOverride` /
`Page.navigate` / `Runtime.evaluate`（轮询 DOM 就绪）/ `Page.captureScreenshot`
（`captureBeyondViewport:true`）。冷启动到出图约 **40 秒**，比 agent-browser 快一个量级。

关键技巧：**不要用截图当唯一证据** —— 同一份脚本里用 `Runtime.evaluate` 把
`getBoundingClientRect()`、`innerText`、`scrollWidth/clientWidth`、`getComputedStyle()`
一起取回来，数值比像素可靠（本轮两个假警报都是靠这个否掉的）。

### ⚠️ 教训：连「看图」本身都不可靠，颜色必须数像素

我一度以为新页面渲染成了**浅色**（白底黑字），据此怀疑前端主题没生效。实测推翻：
`getComputedStyle(document.body).backgroundColor` = `rgb(28,28,30)`、`color` = `rgb(245,245,247)`，
`color-scheme: dark`；PNG 也是 `colortype 2`（无 alpha，排除透明合成问题）、
平均亮度 **46.7**，像素就是 `#1c1c1e`(28,28,30) / `#2c2c2e`(44,44,46)。

决定性判据 —— **用品牌色数像素**（`PIL` 可用，实测 12.1.1）：

| 颜色 | 像素数 |
|---|---|
| `--deep #1c1c1e` | 946,494 |
| `--mid #2c2c2e` | 3,448,420 |
| `--accent #0a84ff` | 21,552 |
| 涨红 `--up #ff453a` | 27,271 |
| 跌绿 `--down #30d158` | 16,328 |
| **反色后的对应值** | **0 / 0** |

→ 页面是**深色**、涨红跌绿也正确，是我把渲染出来的图看反了。
**结论：判断主题/配色/涨跌颜色时不要靠肉眼（哪怕看了 PNG），直接采样像素或读计算样式。**
另注：参考图（通达信）本来就是深色，与本项目深色主题一致，不是冲突。

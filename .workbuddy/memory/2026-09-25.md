## 把 `@app.on_event` 迁移到 `lifespan`（消除 FastAPI DeprecationWarning）

**症状**：启动时打印
`@app.on_event("startup")` / `@app.on_event("shutdown")` is deprecated, use lifespan event handlers instead.
（FastAPI 0.141.1 在**注册时**就发警告，不是运行时。）

**改动**：只动 `stock_picker/app.py`，+64 / −37 行。

1. 新增 `from collections.abc import AsyncIterator` + `from contextlib import asynccontextmanager`。
2. 把「后台任务」（`JOBS` / `_job_update` / `_run_job` / `_new_job`）与「启动预加载」
   （`STARTUP` / `_bootstrap_cfg` / `_run_preload_job`）整体**上移**到依赖装配之后、`app` 构造之前 ——
   因为 `lifespan` 必须能在 `FastAPI(lifespan=...)` 之前定义。
3. `_startup_preload` → `_on_startup`（去掉装饰器）；删掉 `@app.on_event("shutdown")`，
   把它的逻辑提成 `_on_shutdown()`。
4. 新增：
   ```python
   @asynccontextmanager
   async def lifespan(_app: FastAPI) -> AsyncIterator[None]:
       _on_startup()
       try:
           yield
       finally:
           _on_shutdown()
   ```
   `app = FastAPI(..., lifespan=lifespan)`。
5. `_no_cache` 中间件与全部路由位置未变，顺序不受影响。

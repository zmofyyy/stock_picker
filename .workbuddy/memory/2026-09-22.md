## 23:15 修复 K 线抽屉：加宽 + 修掉一处 HTML 结构笔误

**用户诉求**：「K线图宽度宽一点」。

### 改动

1. `style.css`：`.drawer` 宽度 `min(1040px, 94vw)` → **`min(1440px, 95vw)`**。
   K 线图 `.chart { width: 100% }`，自动跟随。
2. `index.html`：**删掉 `.drawer-body` 里多出的一个 `</div>`**（原第 261 行末尾）。
   这是加概念条时引入的笔误，后果不小：
   - `#klineChart` 与 `#drawerFoot` 被解析成 `.drawer` 的子元素，脱离了 `.drawer-body`
   - `.drawer-body` 只剩 **40px 高**，抽屉顶部「计划买入价 / 卖出价 / 数量 + 4 个按钮」整行被压扁
   - 图高被 flex 从 `620px` 压到 `440px`
   - 因为页面照样能打开，肉眼很难发现 —— 属于典型的「沉默失败」

### 实测（1258 × 566 视口）

| 指标 | 改前 | 改后 |
|---|---|---|
| `#klineChart` 父元素 | `drawer`（错） | **`drawer-body`**（对） |
| `.drawer-body` 高 | 40px | 492px |
| `#drawerPlanBar` 高 | 被压扁 | 44px |
| 抽屉宽 | 1039px | 1194px |
| 图表宽 | 1039px（虚高，因脱离了父容器） | **1158px** |
| 图表高 | 440px（被压缩） | 620px（`.chart.tall` 完整生效） |

> 1258 视口下走 `95vw` 分支；在 1920 屏上抽屉取 `1440px` 上限，图表约 1404px。
